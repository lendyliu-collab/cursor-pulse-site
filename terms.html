服务条款

生效及更新日期：2026-11-08。

1. 个人自用项目

cursor-pulse 是个人资料归档项目，不对公众提供账号注册、商业订阅或托管服务。本公开网站提供用途、隐私和使用条件说明。

2. 可用能力与边界

当前已验证的能力为固定 Google Drive 测试文档的云端创建与回读。真实笔记增量同步、Google Sheets 轻量索引与定时同步属于后续规划，不能视为当前已提供的服务。

3. 用户授权和责任

用户仅应处理自己有权访问及保存的内容，并遵守得到大脑、Google 和 GitHub 的适用条款。Google 访问仅限 drive.file 范围；用户应妥善管理凭据，不将其放入公开仓库、网页或聊天。

4. 数据与可用性

项目按现状提供。第三方 API、授权状态、配额、网络或服务变更可能导致失败或延迟，不保证持续可用或完整同步。用户应保留原始资料并自行核验归档结果，不应以测试成功替代备份检查。

5. 停止使用

用户可停止执行脚本、撤销 Google 授权、删除本机配置和 GitHub Secrets，并自行删除 Drive 中的测试或归档文件。撤销访问不等于删除已保存的副本。

6. 更新与联系

能力或处理方式变化时，本页面及隐私政策会相应更新。联系邮箱：lendyliu@gmail.com。
